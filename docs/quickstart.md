# Quickstart — Jejak Kediri

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (local Vinext dev server).

Production check:

```bash
npm run build
npm test
```

Optional database migrations after editing `db/schema.ts`:

```bash
npm run db:generate
```

Platform auth notes: [`docs/platform-vinext.md`](platform-vinext.md).
